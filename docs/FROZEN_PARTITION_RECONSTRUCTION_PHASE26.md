# Frozen-partition reconstruction guard: Phase 26

## Question

Phase 25 re-inferred the two layers after deleting missing pairs. That closed
the missing-harmful-vertex information gap but introduced clean cross-layer
faces in originally safe accepted cases. Can missing-pair reconstruction keep
the full-primary observed layer partition frozen, triangulate only within each
frozen layer, and retain the frozen displacement guard without introducing
endpoint harm on genuinely disjoint fresh cases?

## Design evidence and information boundary

Only the already opened Phase 24/25 design cohorts are used to define this
route:

- score-fit seed `24900804`;
- cutoff-calibration seed `25000804`; and
- the Phase 25 evaluator failure, including contaminated seeds
  `25400804`--`25600804`, as diagnosis only.

None can support Phase 26. Clean reference points, source labels, source
outlier identities, and geometry/topology harm endpoints remain evaluation
only.

The route may use only:

- the full primary point coordinates and their original observed
  shared-trend layer inference;
- the upstream candidate decision;
- the presented retained-pair map and retained primary IDs;
- the presented repeat coordinates; and
- the frozen twelve-coordinate matched-displacement score.

For `missing_10pct`, the original full-primary layer IDs are restricted to the
retained primary IDs and passed unchanged to the existing two-layer surface
constructor. Each frozen layer is triangulated independently. The subset is
not re-clustered. Exact and registration-only profiles keep the original full
primary reconstruction.

This construction prevents a face from crossing the *observed frozen
partition*. It does not prove agreement with hidden source labels, so zero
evaluation endpoint harm remains a required gate rather than an assumed
consequence.

## Rejected conservative alternative

A deletion-only induced subcomplex was checked on the two design cohorts. It
introduced no new face, but deleting 10% of the vertices changed the Betti
signature in 213/216 and 212/216 missing-profile cases. Requiring exact
topology preservation retained only 1/44 and 1/42 focus-safe accepts
(`2.27%`/`2.38%`). This alternative is closed and is not part of Phase 26.

## Case-seed-disjoint fresh protocol

Sequential base seeds `25700804` onward are not fresh at the actual case level.
With the frozen generator

`case_seed = base + count_index*1000003 + stress_index*100003 + repeat*10007`,

each of bases `25700804`, `25800804`, and `25900804` repeats 128 case seeds
already generated by prior panels. The first three consecutive base seeds whose
216-case sets are both mutually disjoint and disjoint from every standard
full-panel case set with bases `20300804`--`25600804` are therefore frozen as:

- Validation A: `27500804`;
- Validation B: `27600804`, opened only if validation A passes; and
- Final held-out: `27700804`, opened only if validation B passes.

Each panel uses the unchanged nine Phase-8 stresses, `N in {96,160,256}`,
eight repeats, 2048 clean-reference points, and 256 endpoint surface samples.
Each panel contains 648 audited profile rows from 216 distinct primary cases.

## Frozen gates

The design score-fit and cutoff-calibration panels must first reproduce all
recorded quantities and pass the same profile gates as fresh panels. Every
profile in every opened panel must:

1. contain at least one original unguarded harmful false-safe;
2. reduce routed harmful false-safes to zero;
3. retain at least 90% of original-safe control/local-bump accepts; and
4. accept zero originally safe cases for which the routed endpoint becomes
   harmful.

Validation B is opened only after validation A passes. The final panel is
opened only after validation B passes. A failed panel closes every later seed;
no opened seed may be used to revise the rule.

Even a complete pass supports only synthetic frozen-partition reconstruction
under the presented-pair simulator. `real_correspondence_supported`,
`real_paired_scan_supported`, `real_trimmed_reconstruction_supported`, and
`deployment_supported` remain false.

## Result

Phase 26 is **not supported**. Before any fresh panel was opened, Ruff and the
diff check passed, all 262 tests passed, and a full-size design-only execution
with nondefault base seeds reproduced the frozen quantities without opening a
fresh panel.

The actual run confirmed that all three 216-case fresh sets have zero overlap
with the prior standard case-seed union and with each other. The design panels
then reproduced and passed:

- score fit: harmful 168 -> 0, focus 132/132, all-safe 354/360, introduced
  endpoint harm 0;
- cutoff calibration: harmful 165 -> 0, focus 126/126, all-safe 351/351,
  introduced endpoint harm 0; and
- cutoff `0.19784302031484602`.

Sequential fresh results were:

- validation A `27500804`: harmful 168 -> 0, focus 123/123, all-safe 360/360,
  introduced endpoint harm 0; every profile passed;
- validation B `27600804`: harmful 165 -> 0, focus 132/132, all-safe 360/360,
  introduced endpoint harm 0; every profile passed;
- final held-out `27700804`: harmful 165 -> 1, focus 132/132, all-safe 360/360,
  introduced endpoint harm 0. Exact and registration passed, but
  `missing_10pct` failed with harmful 55 -> 1.

The limiting final case is `missing_10pct/outliers_01`, N=96, repeat 1, case
seed `28110823`, replicate seed `528110832`, and perturbation seed `930110836`.
The one harmful source outlier remains in the retained set. Frozen-partition
reconstruction reduces its incident harmful faces from six to five but cannot
remove it. Its score `0.19257350714226332` is only
`0.00526951317258270` below the rejection cutoff, so it is accepted.

Post-hoc diagnosis, not a permitted retune, found positive harmful/focus score
gaps in every panel:

- score fit: `0.4741156070800705`;
- cutoff calibration: `0.23912377219798503`;
- validation A: `0.10278799821871698`;
- validation B: `0.4254539457177282`; and
- final: `0.05454504822839301`.

The limiting signature lies inside 8/12 coordinate-wise design-calibration
focus ranges and outside the four tail/amplitude coordinates. Its nearest
design-calibration focus distance is `1.8137950914071372` standardized units.
This is therefore a frozen cutoff-margin transfer failure, not demonstrated
focus-safe representation overlap.

The frozen-partition route fixes Phase 25's reconstruction-induced endpoint
harm: no opened Phase 26 panel contains a newly harmful accepted endpoint, and
all fresh focus-safe cases are retained. It nevertheless misses one retained
harmful outlier at the final gate. Accordingly `phase26_supported=false` and
`frozen_partition_reconstruction_synthetic_supported=false`; all real-data and
deployment flags remain false. Do not lower the cutoff on final seed
`27700804`, and do not reuse `27500804`--`27700804` as fresh evidence. A future
phase may preregister a stricter cutoff rule using opened A/B as design-only
evidence, but must use new case-seed-disjoint panels.
