# P3 — frozen real-data held-out evaluation (predeclared design)

Status: **predeclared design; feasibility confirmed, module built in the same change.**
Date: 2026-07-25 (Asia/Seoul).

This is Gate 1's real deliverable: a **higher-fidelity frozen held-out** evaluation
on real meshes, testing whether any PFTF method (P1, P2, M1) shows value beyond
both B4 and B5 on declared geometry and topology endpoints. The synthetic G5
panel could not clear Gate 1 because of the under-resolved `opposing_sheets`
thin-gap; real meshes do not contain that pathology, so the case mix is a fairer
test.

## 1. Data

Local corpus at `D:\__SFTF_Projects(2026)\sftf_Mesh_Data` (no download): real
Thingi10K shells as `.npz` (`{vertices, facets}`) and CAD/organic meshes as STL.
Each mesh is loaded as a `SurfaceMesh`, centered, and scaled so its bounding-box
diagonal is 1 (characteristic length = 1).

Meshes are partitioned into a **calibration** set (used only to freeze method
parameters) and a disjoint **held-out** set, predeclared before any held-out
number is read. Held-out meshes are never used to tune anything.

## 2. Cases

From each mesh a `RealCase` is generated by area-weighted surface sampling
(`sample_triangle_mesh`): `observed` points (the simulated scan) with added
Gaussian noise, and a dense `reference` cloud from the same mesh. Expected
component and GF(2) Betti targets are read from the mesh via `mesh_statistics`
(evaluation-only). Declared splits: observed density and noise fraction, each
swept over a predeclared grid; every (mesh, density, noise, seed) is one case.

## 3. Methods and freezing

All of B4, B5, P1, P2, and M1 (weight scale frozen at 0.375, the value that
strictly dominated B4 on synthetic calibration) are frozen on the calibration
cases: one multiplier per method chosen to minimize the mean
geometry+topology+complexity objective (references may be used on calibration,
never on held-out). The frozen values are then applied unchanged to every
held-out case.

## 4. Endpoints and the Gate-1 test

Per case and method: surface F-score, normalized squared Chamfer, normalized
Hausdorff (geometry); component error and GF(2) Betti error (topology);
nonmanifold edges; runtime. For each candidate (P1, P2, M1) the casewise
per-endpoint **B4/B5 envelope** margins are computed exactly as in G5:
F-score margin against `max(B4, B5)`, geometry-loss margin against the better
baseline, and topology excess against the better baseline. A candidate clears
Gate 1 on a split if its margins are non-inferior across the declared endpoints;
results are reported per split with the fraction of cases cleared and paired
mean margins with a bootstrap uncertainty interval. Real meshes are complex and
their Betti error is noisy, so a geometry-only clearance is reported alongside
the full clearance rather than hidden.

## 5. Claim boundary

This is a real higher-fidelity held-out comparison, but on a local corpus, not a
licensed benchmark with an external leaderboard, and topology endpoints on
complex shells are noisy. It does not add exact/CGAL parity (that is G4's
separate axis). `promotion_supported` is set true only if a candidate clears the
declared geometry-and-topology envelope on the held-out splits with a
non-degenerate margin; otherwise it stays false and the result is reported as the
honest comparison it is.
